## QQ空间复刻（E:\Project2026\QZone）

**目标**：用 Go + TypeScript 复刻 `user.qzone.qq.com/294388344`（昵称 Change~生活）的空间功能。

### 关键决策
- 后端零第三方依赖：`net/http` + Go 1.22 路由模式，JSON 快照持久化（`data/db.json`，RWMutex + 临时文件 rename 原子写）。
- 前端 Vite + TypeScript，**不用框架**，`innerHTML` + 事件委托渲染，CSS 手写三栏版式（186 / auto / 272）。
- 前端产物 `web/dist` 通过 `//go:embed all:web/dist` 打进单二进制，`main.go` 中 `fs.Sub` 后交给 `api.New`。
- 素材不依赖外网：`internal/store/assets.go` 启动时生成渐变 SVG 的头像/封面/照片到 `data/uploads/seed/`。
  - 踩坑：SVG 里烘焙中文小字，缩略图下糊成噪点；封面文字在移动端与头像重叠 → 最终**素材不带文字**，文字全部交给 HTML。
- 真实页面通过用户在 Edge 中 `Ctrl+S` 存到 `ref/`，解析出真实 IA：顶部「主页/日志/相册/说说/分享/视频/音乐/留言板/个人档/收藏」、访客三档（谁看过我/我看过我/被我挡）、发布器含定时说说与私密评论、个人档字段。
- 无法扫码登录：无摄像头、不应持有真实凭据 → 明确告知用户，改用保存页面 + 截图对照。

### 演示账号
`294388344 / qzone123`（好友账号同样口令，如 `452198703`）。服务默认监听 `:8080`。

### 结构
- `internal/api/{api,auth,feeds,content,social,upload,errors}.go`
- `internal/store/{models,store,seed,assets}.go`
- `web/src/{main,api,components,ui,state}.ts` + `views/*`（login/home/journals/albums/guestbook/friends/visitors/messages/settings/search/space）
- `tools/qa.mjs`：Playwright 登录后按路由整页截图到 `.qa/`，用于版式回归。

### 已知限制
单进程 JSON 存储；无 WebSocket；口令为 sha256 演示级；未实现定时说说、私密评论、视频、黄钻付费与 QQ 互联登录。

### 复用笔记
- Go 1.22 `ServeMux` 的 `{id}` 与 `$` 语法足够支撑 REST 路由，不必引入 chi。
- `http.FileServerFS(embeddedSub)` 可直接托管嵌入的前端，SPA 回落用「先试静态、404 再返回 index.html」。
- Windows 下 Git Bash 会把 `#/home` 这类参数当路径转换，跑 Node 脚本需 `MSYS2_ARG_CONV_EXCL="*"`。

## 第二轮重构：ent + SQLite + 多用户博客

**需求变更**：改用 ent + 纯 Go SQLite（不用 cgo）、开放注册、数据按用户隔离、相册真实上传、说说与日志合并为 Markdown 文章、界面现代化、背景音乐真实播放。

### 关键决策
- 驱动：`modernc.org/sqlite` + `entsql.OpenDB(dialect.SQLite, sql.DB)`；连接池 `SetMaxOpenConns(1)` 避免 SQLITE_BUSY，WAL + busy_timeout。
- ent 生成：`go run entgo.io/ent/cmd/ent generate ./ent/schema`。踩坑记录：
  - Go 1.27 下旧版 x/tools 报 `package "context" without types`，需 `go get golang.org/x/tools@latest`。
  - v0.14 的 m2m `Through` 必须传边实体（不能只传表名，也不能传 nil）→ 改为显式 `PostLike` / `PhotoLike` 实体。
  - 想用 `XxxID` 字段必须 `edge.From(...).Field("xxx_id")` 且在 Fields() 里声明 `field.Int("xxx_id")`。
- 删除要手动级联：先删 Comment / Like / Photo，再删主体，否则外键报错（SQLite `foreign_keys=1`）。
- 口令 bcrypt；会话表 + HttpOnly Cookie(30d)。
- Markdown：marked，渲染前只转义 `&` 和 `<`（转义 `>` 会让引用语法失效）。
- 背景音乐：`media.AmbientWAV` 程序生成 48s WAV（16bit/44.1k 单声道）；播放器遵守自动播放策略——记住开关、首次交互后播放；**播放器自身点击不能被 `arm()` 抢走**，否则先播再暂停。
- 播放器做成 50px 悬浮唱片，hover 展开，避免遮挡正文。

### 坑
- `.field { display:flex }` 会覆盖 `[hidden]`，导致登录页显示注册项 → 加全局 `[hidden]{display:none!important}`。
- Playwright 对 hidden 的 file input 需 `waitForSelector({state:'attached'})` + `setInputFiles(..., {force:true})`。
- 同一 seed 里 cover 与正文首图相同会出现重复大图 → 前端判断正文已含封面则不渲染 hero 封面。

验收脚本：`tools/qa.mjs`（截图）、`tools/e2e.cjs`（音乐播放 / 写作插图 / 相册上传 / 评论）。

## 第三轮：UI 走查与移动端适配

**依据**：ui-taste 的 anti-slop / polish。先列缺陷再改，避免「重设计」掩盖问题。

### 按 anti-slop 清掉的三类问题
1. 靛紫渐变按钮 + 光晕（AI 默认风格）→ 实色强调色 `#2f5d50`，hover 变深，投影降到 1px。
2. 圆角 8/10/12/14/16/18/24 混用 → 定规则：卡片 14、控件 8、媒体 10、通栏 16、胶囊 999。
3. 同一意图四种文案（写文章/写点什么/写一篇/开始写作）→ 统一为「写文章」。

### 顺带修的实质缺陷
- 顶栏/CTA 用 `backdrop-filter` 毛玻璃 + 彩色光斑 → 改实色纸面与单一强调线。
- `<a class="feature-cover">` 同时 `aspect-ratio` + `max-height` 会反向压窄宽度（569px 而非 796px）→ 改 `width:100%; height:300px`。
- 素材生成用 `fmt.Sprintf` 参数错位，产出带 `%!s(MISSING)` 的坏 SVG（页面出现破图）→ 改 `{key}` 占位符模板。
- 示例照片原来是一个巨大白色光斑，裁切后像白块 → 改为三种构图（地平线/雾面/远山倒影），降低光晕。
- `<input>` 在登录页没加 `.input` 类，样式完全丢失；`[hidden]` 被 `.field{display:flex}` 覆盖 → 全局 `[hidden]{display:none!important}`。

### 移动端（新增）
- 底部五项页签替代被隐藏的顶部导航（43px 触控高度 + 安全区）。
- hero 纵向堆叠、头像 64、标题 22；自己的主页在移动端隐藏 hero 里的重复入口。
- 文章头部：作者与时间分行，编辑/删除另起一行。
- 播放器在 ≤720px 变为底部信息条（页签之上），body 增加 `has-bgm` 留白类。
- 9 页逐页检查：无横向溢出、无控制台错误；页签跳转与选中态正确。

### 验收方式修正
整页截图中超出视口的 SVG 会漏绘成白块，是 Chrome 的合成行为，不是布局 bug。核对版式改用视口/元素截图。

## 第四轮：上传上限、免费曲库、专业编辑器

### 1. 大图上传
- 服务端上限写死 10MB → 改为 `-max-image`（默认 30MB）/ `-max-audio`（默认 50MB），错误信息带上实际上限。
- 真正的问题是原图太大：新增 `web/src/image.ts`，长边 >2560 或 >2MB 时用 canvas 重编码 WebP（质量 0.9 起，逐步降到 0.6，必要时缩尺寸），目标 ≤3MB。
- 实测 34.4MB/4000×3000 噪声图 → 2.58MB webp，上传成功；编辑器和相册都走这条路径。

### 2. 音乐
- QQ 音乐 `u.y.qq.com/cgi-bin/musicu.fcg` 搜索返回 `req.code 2001`（需签名），不绕过；不抓版权曲目。
- 改为内置曲库：`media.AmbientTrack(kind)` 合成 3 首（夜航/晨雾/远山），`GET /api/music/library` 暴露；支持上传与直链。
- 播放器按「url + title」工作，后续接授权曲库无需改前端。

### 3. 编辑器
- 仿 CSDN：工具栏分组、编辑/分屏/预览三态、`Ctrl+B/I/K/S`、行前缀切换（标题/引用/列表可反选）。
- 粘贴：`paste` 事件读 `clipboardData.items` 里的 image → 压缩 → 上传 → 光标处插 `![](url)`；另支持拖拽到编辑区。
- 草稿：1.2s 防抖写 localStorage，重进提示恢复/丢弃。
- 踩坑：`.md-toolbar` 的移动端规则第一次没插入（替换目标字符串不存在），导致手机上工具栏换三行；改成文件末尾追加媒体查询后恢复单行滚动。

### 验收
`tools/features.cjs`：真实剪贴板写入 + Ctrl+V 粘贴成功、34.4MB→2.58MB、工具栏 `## **文字**`、分屏 370/370、草稿已保存、曲库 3 首、选《晨雾》后 audio.src=music-dawn.wav 且 playing=true、无 console 错误。
